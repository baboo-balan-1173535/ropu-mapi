Rōpū Mapi puts a group of cars on one shared route. Each driver sees where the others are, and the app speaks up when someone stops or takes a wrong turn.

Rōpū Mapi means “group map” in te reo Māori.

    How it’s built

    Built by one developer using open map data. The app has no paid map licence.

    Maps and routing
    MapLibre GL on OpenStreetMap data. Routes come from OSRM, and Valhalla plans the way around closed roads.
    Road notices
    The NZ Transport Agency state highway feed. If an active closure sits on your route, the route is re-planned around it.
    Convoy sync
    A Node.js and Socket.IO server. Drivers join with a temporary callsign, and the app has no accounts or passwords.
    App shell
    One web codebase inside a native Android shell (Capacitor), with native text-to-speech and a foreground location service for screen-off driving.
    Languages
    English and Traditional Chinese (Taiwan). Try the 繁中 button under the phone.
    Releases
    Built in GitHub Actions. Each release candidate has to pass an emulator soak test before it goes to Google Play.

    This is an interactive preview that runs on sample data. The map is a simplified drawing of Canterbury and Banks Peninsula. The speed limits, roadworks, callsigns and convoy code shown here are examples. The real app uses live GPS and open map data.
